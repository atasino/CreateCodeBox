# Learn card: Terminal

## In one line
The Terminal is a window where you ask your computer to do things with text. You type one line and press Enter.

## Think of it as
A note that you hand to a helper. The helper does what the note says, and nothing else.

## What happens now
- On a Mac: press ⌘ Space, type "Terminal", and press Enter.
- On Windows: open "Git Bash" from the Start menu.
- When `pm` (the assistant you talk to) says "open a separate Terminal", open a second, new window. Do not use the window where Claude Code runs.
- Paste the line that `pm` gives you, and press Enter. On a Mac, paste with ⌘ V. In Git Bash, paste with Shift + Insert, or right-click.

## Watch out
- If you do not understand a line, ask `pm` what it does before you press Enter.
- When a key or password is asked for, nothing shows on the screen as you type. That is normal. The text is still entered.
- Keys are always typed in the separate window. The card `secrets` says why.
- To stop a running command, press Control + C.

## The technical name
Terminal, command line, or shell. The Mac uses `zsh`. Git Bash uses `bash`.
