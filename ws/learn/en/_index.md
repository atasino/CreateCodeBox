# Learn cards

`pm` is the assistant you talk to in this workspace.

Each card is one short page. `pm` shows a card just before the step it explains. You can read any card with `bash ws/bin/ws.sh learn <name>`.

`start here` cards help from the first day. `later` cards matter when you use GitHub or connect a service.

| Card | One line | When |
|---|---|---|
| `terminal` | The window where you type one line to ask your computer to do something | start here |
| `folder` | Folders are boxes inside boxes, and a path is the list of boxes to a file | start here |
| `secrets` | Keys are secrets. Type them in a separate window, never in the chat | start here |
| `systemtest` | Done means you really see every result you asked for | start here |
| `save` | Keep a dated record of your work on your computer | start here |
| `github` | Keep a copy online, work on a branch, or bring in a repo you have | later |
| `private-public` | Private means you decide who can open it. Public means everyone. Start private | later |
| `mcp` | A connection that lets Claude use an online service for you | later |

Pictures: `map.html` is The GitHub road. `overview.html` shows the whole flow, from ask to done.
