# 学びカード

`pm` は、このワークスペースで、あなたが話しかけるアシスタントです。

カードは、どれも短い 1 ページです。`pm` は、カードが説明するステップの直前に、そのカードを見せます。どのカードも `bash ws/bin/ws.sh learn <name>` で読めます。

「最初に」のカードは、最初の日から役に立ちます。「あとで」のカードは、GitHub を使うときや、サービスを接続するときに大切です。

| カード | 1 行の説明 | 印 |
|---|---|---|
| `terminal` | 1 行打って、パソコンに何かをお願いするウィンドウ | 最初に |
| `folder` | フォルダは箱の中の箱で、パスは、ファイルまでの箱の順番 | 最初に |
| `secrets` | 鍵は秘密です。チャットではなく、別のウィンドウに打つ | 最初に |
| `systemtest` | 完成とは、頼んだ結果のすべてを、実際に見られること | 最初に |
| `save` | 作業の記録を、日付つきで、あなたのパソコンに残す | 最初に |
| `github` | コピーをネット上に置く、ブランチで作業する、持っている repo を持ち込む | あとで |
| `private-public` | 非公開は、誰が開けるかをあなたが決める。公開は誰でも。最初は非公開 | あとで |
| `mcp` | Claude があなたの代わりにネット上のサービスを使うための接続 | あとで |

図: `map.html` は「GitHub の道のり」です。`overview.html` は、最初の質問から完成まで、全体の流れを見せます。
