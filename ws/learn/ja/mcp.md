# 学びカード: MCP

## 一言で
MCP は、Claude がネット上のサービスにつないで、あなたの代わりに使うための方法です。

## たとえるなら
テーブルタップに、機器を 1 つ差し足すようなものです。接続 1 つが、差し込み 1 つです。何を差すかは、あなたが決めます。

## いま起きること
- あなたがやるのは、サービスへの登録、本人の確認、「許可」を押すことです。
- 残りは、Claude が、その接続を通して行います。
- サービスの鍵は、Claude には渡らないように作ってあります。鍵は、鍵の受け渡しだけをする小さなプログラムが、必要なときにだけ接続へ届けます。この流れは、まだ実際のサービスでは確かめられていません。
- サービスを接続したいとき、`pm`（あなたが話しかけるアシスタント）が手順を見せます。

## 気をつけること
- 接続するのは、あなたが選んだサービスだけにしてください。接続が増えるほど、Claude にできることが増えます。
- Gakaso（私たちの製品）以外の接続について、このワークスペースが確かめるのは道具の名前だけです。名前から書き込みや変更をする道具だと分かる物は、「作る」段階が始まるまで止めます。各セッションの最初のメッセージでも止めます。足す前に、その接続の道具で何ができるのかを読んで確かめてください。
- 鍵を設定ファイルに書かないでください。そのファイルを公開すると、誰でも鍵を見られます。
- サービスの設定ページに鍵が表示されるときは、鍵をコピーして貼る操作を、あなたが自分で行います。そのとき Claude は、画面を見ないよう指示してあります。

## 裏の名前
MCP は Model Context Protocol の略です。接続は MCP サーバー（MCP server）と呼ばれます。設定は `.mcp.json` にあります。
