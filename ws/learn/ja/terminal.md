# 学びカード: ターミナル

## 一言で
ターミナルは、パソコンに「文字で」お願いをするウィンドウです。1 行打って、Enter キー（Mac では return キー）を押します。

## たとえるなら
お店のカウンターで、メモを店員さんに渡すようなものです。店員さんは、メモに書いてあることだけをします。

## いま起きること
- Mac では、command キーとスペースキーを同時に押し、「ターミナル」と入力して、Enter を押します。
- Windows では、スタートメニューから「Git Bash」を開きます。
- `pm`（あなたが話しかけるアシスタント）が「別のターミナルを開いてください」と言ったら、新しいウィンドウをもう 1 つ開きます。Claude Code が動いているウィンドウは使いません。
- `pm` が渡す 1 行を貼り付けて、Enter を押します。貼り付けは、Mac では command + V、Git Bash では Shift + Insert か右クリックです。

## 気をつけること
- 意味が分からない 1 行は、Enter を押す前に、何をするのかを `pm` に聞いてください。
- 鍵やパスワードを求められたとき、打っても画面には何も出ません。これは正常です。文字は入力されています。
- 鍵は、いつも別のウィンドウに打ちます。理由は、カード `secrets` にあります。
- 動いているものを止めたいときは、Control + C を押します。

## 裏の名前
ターミナル、コマンドライン、シェルと呼ばれます。Mac は `zsh`、Git Bash は `bash` を使います。
