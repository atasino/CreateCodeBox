# Security

If you find a weakness in CreateCodeBox, please tell us in private. For example, a way for a key to leak, or a way to get around the guards.

- Use [Report a vulnerability](https://github.com/atasino/CreateCodeBox/security/advisories/new). On the repository page, it is under the "Security and quality" tab. The report is private and goes to the maintainers.
- Do not write the details in a public issue or in Discussions.
- Do not send real keys or passwords. Use made-up ones.
- We cannot promise when we will reply.

The guards in this workspace have limits. The limits are described in [docs/security.md](docs/security.md).
